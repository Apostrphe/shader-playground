A real-time OpenGL shader editor using GLFW, GLAD, and ImGui.
Edit and preview GLSL fragment shaders live.

FEATURES:
1. Live shader editing (GLSL)
2. Fragment shader hot-reload
3. Minimal ImGui interface
4. Real-time OpenGL rendering


BUILD INSTRUCTIONS:

REQUIREMENTS:
C++17 compiler
CMake
GLFW
GLAD
ImGui

STEPS:
git clone https://github.com/yourusername/shader-playground.git
cd shader-playground
mkdir build && cd build
cmake ..
make
./ShaderPlayground
